# AaTu Strike

加入弹射物爆头、潜行蓄力、定向冲刺、床面反弹与箭射西瓜。

## 成品

Minecraft 1.21.1。

- NeoForge [aatu-strike-1.0.0.jar](artifacts/neoforge/aatu-strike-1.0.0.jar)

[玩法与配置](GUIDE.md)

[服务端配置示例](config-examples/aatu-strike.toml)

## 构建

使用 JDK 21，在仓库根目录执行 `.\gradlew.bat :aatu-strike:assemble -x test`。
